## **Beginner Level (Foundations)**

> Focus: Understanding devices, LAN connectivity, IP addressing, and basic switch/router functions.

1. [01_PC_to_PC_Connection](Beginner/01-PC-to-PC) – Connect two PCs directly, assign IPs, test ping.
    
2. [02_PC_to_Switch_Connection](Beginner/02-PC-to-Switch) – Connect multiple PCs to a switch, test LAN connectivity.
    
3. [03_PC_to_Router_Default_Gateway](Beginner/03-PC-to-Router-Default-Gateway) – Connect PCs through a router, configure default gateway.
    
4. [04_Basic_IP_Addressing_Subnetting](Beginner/04-Basic-Subnetting) – Assign multiple subnets, test connectivity.
    
5. [05_Simple_Switch_Configuration](Beginner/05-Simple-Switch-Config) – Configure VLANs, assign ports, test communication.
    
6. [06_Hostname_and_Password_Configuration](Beginner/06-Hostname-and-Password-Configuration) – Configure device hostnames, console, and enable passwords.
    
7. [07_Static_IP_Subnet_Assignment](Beginner/07-Static-IP-Subnet) – Practice different subnet masks, understand subnetting impact.
    
8. [08_Cabling_Types_HandsOn](Beginner/08-Cabling-Types) – Use straight-through, crossover, and console cables correctly.
    
9. [09_Ping_Tracert_Basics](Beginner/09-Ping-Tracert-Basics) – Practice ping, traceroute, and basic connectivity testing.
    
10. [10_Simulation_Mode](Beginner/10_Simulation_Mode) – Learn to simulation and understand the flow.

## **Intermediate Level (Routing & VLANs)**

> Focus: VLANs, inter-VLAN routing, static & dynamic routing, ACLs, and small enterprise scenarios.

1. [01_InterVLAN_Routing_RouterOnAStick](Intermediate/01-InterVLAN-Routing-RouterOnAStick) – Configure multiple VLANs and inter-VLAN routing.
    
2. [02_Static_Routing_MultiRouter](Intermediate02_Static_Routing_MultiRouter) – Connect 2-3 routers, configure static routes, test connectivity.
    
3. [03_RIP_Routing_Basics](Intermediate03_RIP_Routing_Basics) – Implement RIP, verify routing tables, test network reachability.
    
4. [04_OSPF_Basic_Configuration](Intermediate/04_OSPF_Basic_Configuration) – Configure OSPF, multiple areas, verify neighbor relationships.
    
5. [05_ACL_Basics_IP_Filtering](Intermediate/05_ACL_Basics_IP_Filtering) – Implement standard and extended ACLs to block/allow traffic.
    
6. [06_DHCP_Across_Multiple_Subnets](Intermediate/06_DHCP_Across_Multiple_Subnets) – Configure DHCP server and client across multiple subnets.
    
7. [07_NAT_PAT_Basic_Labs](Intermediate/07_NAT_PAT_Basics_Labs) – Configure NAT and PAT to simulate internet access.
    
8. [08_VLAN_Trunking_and_VTP](Intermediate/08_VLAN_Trunking_and_VTP) – Implement VLAN trunking, VTP configuration, and switch management.
    
9. [09_Static_and_Default_Route_Combos](Intermediate/09_Static_and_Default_Route_Combos) – Mix static routes with default routes for branch networks.
    
10. [10_Basic_Wireless_LAN_Setup](Intermediate/10_Basic_Wireless_LAN_Setup) – Configure a wireless network, SSID, WPA2, connect PCs
