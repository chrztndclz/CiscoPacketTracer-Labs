## **Advanced Level (Enterprise & WAN)**

> Focus: WANs, enterprise routing protocols, security, wireless, QoS, and troubleshooting.

00_Network_Devices_Introduction – Identify common networking devices, their functions, interfaces, and proper cable connections.

01_PC_to_PC_Connection – Connect two PCs directly, assign IPs, test ping.

02_PC_to_Switch_Connection – Connect multiple PCs to a switch, test LAN connectivity.

03_PC_to_Router_Default_Gateway – Connect PCs through a router, configure default gateway.

04_Basic_IP_Addressing_Subnetting – Assign multiple subnets, test connectivity.

05_Basic_CLI_Navigation – Learn basic Cisco IOS commands, navigation modes, and configuration file management.

06_Hostname_and_Password_Configuration – Configure device hostnames, console, and enable passwords.

07_ARP_and_MAC_Address_Basics – Understand MAC addressing, ARP resolution, and how devices communicate within a local network.

08_Static_IP_Subnet_Assignment – Practice different subnet masks and understand subnetting impact.

09_Cabling_Types_HandsOn – Use straight-through, crossover, and console cables correctly.

10_Simple_Switch_Configuration – Configure VLANs, assign ports, and test communication.

11_Ping_Tracert_Basics – Practice ping, traceroute, and basic connectivity testing.

12_Packet_Tracer_Simulation_Mode – Use Simulation Mode to observe ARP, ICMP, and packet flow through the network.
